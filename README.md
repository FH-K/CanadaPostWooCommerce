# 🍁 Canada Post WooCommerce Plugin

## About This Plugin

This **WooCommerce Canada Post Shipping Plugin** was developed by **Farboud FHK** to provide seamless integration between WooCommerce stores and Canada Post shipping services. As a dedicated developer passionate about e-commerce solutions, I created this plugin to solve the common challenges that Canadian online stores face when implementing reliable shipping calculations.

## 🚀 What This Plugin Does

This plugin transforms your WooCommerce store into a fully integrated Canada Post shipping solution by:

- **Real-time Rate Calculation**: Instantly calculates shipping costs using the official Canada Post API
- **Automatic Package Sizing**: Intelligently determines package dimensions based on your products
- **Enhanced Postal Code Validation**: Ensures accurate delivery with comprehensive Canadian postal code validation (A1A 1A1 format)
- **Order Management**: Streamlines your workflow with direct shipment creation and label generation
- **Bulk Operations**: Process multiple orders efficiently with bulk shipment creation
- **Enterprise Security**: Multi-layered security features to protect your store and customer data
- **Regular Parcel Focus**: Optimized for Canada Post Regular Parcel service with streamlined functionality

## 🔧 Installation & Setup

### Requirements

- WordPress 5.0 or higher
- WooCommerce 5.0 or higher
- PHP 7.4 or higher
- Canada Post API credentials

### Quick Setup

1. **Upload Plugin**: Upload the plugin files to your WordPress plugins directory
2. **Activate**: Activate the plugin in your WordPress admin
3. **Configure**: Go to WooCommerce → Settings → Shipping → Canada Post
4. **Enter Credentials**: Add your Canada Post API username, password, and customer number
5. **Set Store Address**: Configure your store's postal code and address
6. **Test**: Test with a Canadian postal code like M5K 1A0

### Configuration Options

- **API Credentials**: Username, password, and customer number
- **Store Information**: Postal code, address, city, and province
- **Environment**: Sandbox or production mode
- **Default Dimensions**: Package dimensions for products without specific measurements
- **Debug Mode**: Enable/disable debug logging (disabled in production)
